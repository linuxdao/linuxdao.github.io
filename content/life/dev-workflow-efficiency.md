终端层的效率核心是「会话持久化 + 快速跳转」：tmux 或 zellij 让 SSH 断开后任务继续运行，配合 zoxide 记录访问过的目录、fzf 做历史命令与文件模糊搜索，日常操作几乎不需要手打完整路径。这些工具的共同点是学习曲线平缓，但每天都能省下大量重复敲击。

编辑器方面，配置应当「代码化」：VS Code 用 Settings Sync 或 dotfiles 仓库管理 settings.json 与扩展清单，Neovim 用户直接把配置放进 Git。真正的收益不在单个快捷键，而在团队与多机环境下一分钟内恢复完整工作环境，换机器不再有冷启动成本。

自动化脚本优先处理「高频且规则明确」的场景：项目初始化（克隆、装依赖、起服务一键完成）、发布流程（构建、打 tag、推送、生成 changelog）、日志与备份的定时清理。判断标准很简单——一个操作如果每周手动做三次以上，就值得花半小时写成脚本沉淀下来。
